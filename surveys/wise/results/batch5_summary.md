added for the picky-network hypothesis (`targets/universal_v2`,

## Curation notes

- Fomalhaut is Gaia-saturated: Hipparcos-2 solution adopted (Sirius /
  Procyon precedent; single star, no barycentre correction). RV +6.5 ±
  0.5 km/s (Gontcharov 2006).
- 82 Eri (RUWE 1.98) and σ Dra (RUWE 1.68) carry ×3-inflated
  uncertainties (τ Cet precedent); both are saturation-bright with
  clean Hipparcos–Gaia proper-motion anomalies, so the inflation is a
  formality at WISE precision.
- Nine white dwarfs (GJ 293, 318, 518, 915, 1087, 1276, 2012, 3112,
  13157) lack catalogue RVs: 0 ± 50 km/s allocation (van Maanen
  precedent, locus impact < 0.1″).
- GJ 229 B (T dwarf) and GJ 667 AB (no Gaia solutions) are not
  searched; the systems are represented by A and C respectively.

## Pipeline lessons

- A single IRSA TAP 503 killed a 6-hour screening run; `tap_query`
  now retries 5xx/connection errors with backoff. (A concurrent ZTF
  screening session shares the IRSA budget.)
- The hypothesis-version pin must be bumped *before* launching a
  batch: the batch-5 coarse/precise records carry the v1.4 label
  (physics identical; per the v1.1 addendum, earlier-pinned records
  remain valid). Calibration was rerun under v1.5
  (`run-935f8d521a31` supersedes `run-13231f394bac`).
- The exceedance census is no longer a manual step.
- An AnalysisRun id must change when the photometry convention
  changes: the first corrected-scale recalibration reproduced
  `run-935f8d521a31` verbatim because the config hash ignored the
  kernel; the convention is now part of the config (v0.2.1).
- Long `sample_tensor` runs write only at the end; a pattern-matched
  process kill from another session cost one full rebuild. Run under a
  distinct script name when sharing the machine.
